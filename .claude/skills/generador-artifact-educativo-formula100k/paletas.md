## Cómo aplicar la paleta

### En el header
```jsx
<header style={{background:"linear-gradient(135deg,#HEX1,#HEX2,#HEX3)"}}>
```

### En botones de acción
```jsx
className="bg-violet-600 hover:bg-violet-700 text-white"
```

### En progress bars
```jsx
style={{background:"linear-gradient(90deg,#HEX1,#HEX2)"}}
```

### En cajas destacadas (intro de cada sub-tab)
```jsx
className="bg-gradient-to-r from-violet-50 to-pink-50 border border-violet-200"
```

### En back de flashcards
```jsx
style={{background:"linear-gradient(135deg,#HEX1,#HEX2,#HEX3)"}}
```

## Reglas de uso

1. **Header gradient** debe ser fuerte y distintivo (3 colores)
2. **Accent color** debe ser legible sobre fondo blanco (usar shade 600+)
3. **Cajas suaves** usan shade 50-100 del accent color
4. **Borders** usan shade 200-300 del accent color
5. **Texto sobre accent** siempre blanco

## Cuando agregues una paleta nueva

Documéntala aquí con:
- Nombre del artifact
- Gradient HEX completo
- Accent color
- Razón de la elección (ej: "rojo para urgencia", "verde para crecimiento")
